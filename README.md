# Мой день

[Открыть рабочую форму](https://script.google.com/macros/s/AKfycbxNM1zOiq0sRq97CiDIdMwuioKS0bpqKjfL_vLwayYk8lnGDYfQwxcfAsO-TqsmN_TXUg/exec)

Пошаговый ежедневный отчёт на русском языке. Рабочая версия размещается как Google Apps Script Web App; код можно хранить в GitHub. Открытый отдельно Index.html работает в явно обозначенном локальном тестовом режиме и не отправляет данные в Google.

## Что реализовано

- Участник запоминается в браузере; стабильные ID p1, p2, p3.
- Цель хранится в Google Таблице и сохраняется при переходе с шага 2; её можно редактировать.
- Сегодня, завтра, инсайт — обязательные поля, до 5000 символов.
- Черновик раздельный для участника и омской даты.
- Дата определяется сервером в Asia/Omsk. При переходе через полночь ежедневные поля очищаются, старый локальный черновик остаётся.
- Один отчёт в день. Повтор запроса после потери связи не создаёт дубликат. Для редактирования используется версия записи; параллельный устаревший запрос не перезаписывает данные.
- Исторические строки сохраняют цель на момент отправки.
- Ввод записывается как текст, включая строки, похожие на формулы.

## Таблица

https://docs.google.com/spreadsheets/d/1X-wT68o9aM6ELnyjciI8SmgezJ8eGncLR_yzIULMwqs/edit

Первые пять столбцов: дата, цель, сегодня, завтра, инсайт. Шестой — время отправки. Скрытые G:H — версия и ID отправки. Скрытый лист `_Участники` связывает стабильные ID с листами и хранит актуальные цели. Таблица остаётся приватной.

## Развёртывание

1. В Apps Script добавить Code.gs и HTML-файл Index с содержимым Index.html.
2. В настройках проекта включить отображение appsscript.json; скопировать приложенный манифест.
3. Установить свойство скрипта SPREADSHEET_ID. В этой копии setup_ содержит ID созданной таблицы как начальное значение.
4. Для первичной настройки временно переименовать `setup_` в `setup`, сохранить, выбрать `setup` и выполнить. Подтвердить Google-доступ к таблицам. После выполнения обязательно вернуть имя `setup_` перед публикацией. Приватные функции с подчёркиванием скрыты от вызовов посетителей и от списка запуска в редакторе.
5. Развернуть как веб-приложение: выполнять от имени владельца, доступ — все пользователи. Если организационная политика не позволяет анонимный доступ, потребуется разрешённый личный аккаунт или другая схема размещения.
6. Участникам отправлять ссылку развёртывания с `/exec`, не `/dev` и не ссылку редактора.
7. При обновлении кода: Управление развёртываниями → изменить → новая версия. Это сохраняет постоянную ссылку.

## Замена участников

Изменять `name` в массиве PARTICIPANTS в Code.gs, сохраняя ID. Повторно выполнить разовую настройку, вернуть приватное имя и обновить версию развёртывания. Существующий лист переименуется с сохранением истории. В Index.html такой же массив используется только для локального демо; рабочая форма получает список с сервера.

## Доступ

Выбор имени не является авторизацией. Посетитель общей ссылки может выбрать любого участника, увидеть его актуальную цель и сегодняшний отчёт, а также изменить их. Это согласованный тестовый вариант. Для личных/конфиденциальных отчётов нужны персональные ссылки или вход в аккаунт.

## Локальная проверка

Открыть Index.html либо запустить `python3 -m http.server 4173` в папке проекта и открыть http://localhost:4173/Index.html. В тестовом режиме ответы остаются только в текущем браузере. После подключения Apps Script демо-данные не мигрируют в облако.

## GitHub

В репозиторий загружаются исходники, но не ответы и не ключи. GitHub Pages может показывать демо Index.html; рабочая форма использует ссылку Google Apps Script. Публикация статического файла сама по себе не подключает Google Таблицу.
