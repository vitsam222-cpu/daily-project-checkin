# Мой день

[Открыть рабочую форму](https://vitsam222-cpu.github.io/daily-project-checkin/)

Пошаговый ежедневный отчёт на русском языке. Рабочая версия размещается как Google Apps Script Web App; код можно хранить в GitHub. Открытый отдельно Index.html работает в явно обозначенном локальном тестовом режиме и не отправляет данные в Google.

## Что реализовано

- Участник запоминается в браузере; стабильные ID u1–u8.
- Цель хранится в Google Таблице и сохраняется при переходе с шага 2; её можно редактировать.
- Сегодня, завтра, инсайт — обязательные поля, до 5000 символов.
- Черновик раздельный для участника и омской даты.
- Дата определяется сервером в Asia/Omsk. При переходе через полночь ежедневные поля очищаются, старый локальный черновик остаётся.
- Один отчёт в день. Повтор запроса после потери связи не создаёт дубликат. Для редактирования используется версия записи; параллельный устаревший запрос не перезаписывает данные.
- Исторические строки сохраняют цель на момент отправки.
- Ввод записывается как текст, включая строки, похожие на формулы.

## Развёртывание

1. В Apps Script добавить Code.gs и HTML-файл Index с содержимым Index.html.
2. В настройках проекта включить отображение appsscript.json; скопировать приложенный манифест.
3. Установить свойство скрипта SPREADSHEET_ID. В этой копии setup_ содержит ID созданной таблицы как начальное значение.
4. Для первичной настройки временно переименовать `setup_` в `setup`, сохранить, выбрать `setup` и выполнить. Подтвердить Google-доступ к таблицам. После выполнения обязательно вернуть имя `setup_` перед публикацией. Приватные функции с подчёркиванием скрыты от вызовов посетителей и от списка запуска в редакторе.
5. Развернуть как веб-приложение: выполнять от имени владельца, доступ — все пользователи. Если организационная политика не позволяет анонимный доступ, потребуется разрешённый личный аккаунт или другая схема размещения.
6. Участникам отправлять ссылку развёртывания с `/exec`, не `/dev` и не ссылку редактора.
7. При обновлении кода: Управление развёртываниями → изменить → новая версия. Это сохраняет постоянную ссылку.

## Замена участников

Изменять `name` в массиве PARTICIPANTS в Code.gs, сохраняя ID. Повторно выполнить разовую настройку, вернуть приватное имя и обновить версию развёртывания. Существующий лист переименуется с сохранением истории. В Index.html такой же массив используется только для локального демо; рабочая форма получает список с сервера.

## Доступ

Выбор имени не является авторизацией. Посетитель общей ссылки может выбрать любого участника, увидеть его актуальную цель, вчерашний план и историю отчётов, а также изменить цель и сегодняшний отчёт. Форма рассчитана на доверенную группу. Для личных/конфиденциальных отчётов нужен вход в аккаунт или отдельная проверка доступа.

## Локальная проверка

Открыть Index.html либо запустить `python3 -m http.server 4173` в папке проекта и открыть http://localhost:4173/Index.html. В тестовом режиме ответы остаются только в текущем браузере. После подключения Apps Script демо-данные не мигрируют в облако.

## GitHub

В репозиторий загружаются исходники, но не ответы и не ключи. GitHub Pages публикует папку docs из main. docs/index.html автоматически перенаправляет участников в рабочую форму Google Apps Script; при отключённом JavaScript работают meta refresh и обычная ссылка. При смене адреса развёртывания обновите URL в docs/index.html.

## Ежедневное заполнение
После выбора участника и сохранения цели форма открывает сразу три ежедневных вопроса. Имя и цель остаются доступными для изменения. Над вопросом о сегодняшних задачах показан план из вчерашнего отчёта (по Омску); при пропуске вчерашнего дня блок отсутствует. Если сегодняшний отчёт уже отправлен, при входе показываются его ответы, время отправки по Омску и кнопка редактирования. Изменения обновляют существующую строку.

## Удобство заполнения

- На телефоне кнопки закреплены снизу.
- Черновик сохраняет ответы, текущий вопрос и ID неподтверждённой отправки. После возвращения доступно продолжение заполнения.
- Статус подтверждает сохранение на устройстве. При запрете хранилища выводится предупреждение. Повтор отправки после ошибки не создаёт дубль. Загрузка формы и история требуют интернета.
- Для ежедневных полей достаточно 1–2 предложений; все три поля обязательны.
- На последнем шаге раскрывается просмотр всех ответов с адресным редактированием и возвратом к проверке.
- История выбранного участника доступна по датам, по 10 отчётов за раз. Просмотр истории сохраняет текущий черновик. Исторические цели показаны на момент отправки.

Проверки: `node --test tests/backend.test.cjs`. Проверки с заполнением проводятся локально, без тестовых ответов в рабочей таблице.

## Отчёты участников
Раздел доступен с первого экрана, при заполнении, восстановлении черновика и после отправки. Выбор автора для просмотра отделён от автора текущего отчёта: черновик, выбранное имя и шаг заполнения сохраняются. Отчёты показываются по датам, только для чтения, с подгрузкой по 10 записей.

Навигация оформлена единым меню вкладок: «Заполнить отчёт», «Мои отчёты», «Отчёты участников». Активная вкладка выделена, клавиатура поддерживает стрелки, Home/End и Enter. Переключение между разделами сохраняет состояние заполнения. До выбора автора вкладка «Мои отчёты» предлагает выбрать себя.
